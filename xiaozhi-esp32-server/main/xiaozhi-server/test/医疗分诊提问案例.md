# 校园医疗分诊 — 提问与回复案例

> 对应服务端工具 `campus_medical_triage`（含 LangGraph 安全门 + `execute_medical_turn` 状态机）。  
> 用于测试、培训与验收；实际话术以运行日志/接口返回为准。

---

## 模块一：外伤（破皮、流血、碰撞、摔跤、扭伤等）

### 首轮命中外伤关键词

| 用户示例 | 系统典型回复（摘要） |
|----------|----------------------|
| 我头流血了 | 先确认怎么弄伤：摔倒蹭破皮、桌椅淤青、猫狗抓咬、生锈铁钉？并提示深刺伤/动物伤需医务室评估破伤风/狂犬疫苗 |
| 膝盖擦破皮了 | 同上 |
| 刚才跑步摔跤了 | 同上 |

### 状态：伤口性质（`trauma_injury_type`）

| 用户再答 | 走向 |
|----------|------|
| 被猫抓了 / 狗咬了 / 生锈钉子扎了 | 立即结束：务必去医务室，评估破伤风/狂犬疫苗；本端不处理 |
| 扭伤 / 脚踝肿 | 进入扭伤：问 48 小时内还是已多天仍有淤血 |
| 蹭破皮 / 桌椅撞的 / 普通划伤 | 进入创面清洁：问有无沙石泥土、是否仍在渗血 |

### 状态：创面清洁（`trauma_cleanliness`）

| 用户再答 | 系统典型回复（摘要） |
|----------|----------------------|
| 有沙子、泥土、异物 | 有异物勿自贴创可贴；去医务室生理盐水冲洗清创 |
| 没有脏东西，血止了/少量渗血 | 轻微擦伤；碘伏消毒说明；可下发棉签/敷料（设备 JSON：`device_actions`） |

### 状态：扭伤（`sprain_time` → `sprain_allergy_check`）

| 用户再答 | 系统典型回复（摘要） |
|----------|----------------------|
| 今天扭的 / 48 小时内 / 刚崴的 | 急性期：冰敷、勿揉药酒；去医务室取冰袋 |
| 好几天了 / 还有淤血 | 问是否胶布过敏；不过敏可引导弹性绷带（`device_actions`） |
| 过敏 | 去医务室替代固定方案 |

## 模块二：内科 / 身体不适（头疼、恶心、肚子疼、发烧等）

### 首轮命中内科关键词

| 用户示例 | 系统典型回复（摘要） |
|----------|----------------------|
| 头疼 / 恶心 / 肚子疼 / 发烧 | 问是否量过体温、发冷发热；请靠近体温窗口；可带 `read_infrared_temperature` |

### 状态：体温与全身症状（`internal_temp_check`）

| 条件或用户说法 | 系统典型回复（摘要） |
|----------------|----------------------|
| 设备上报 `temperature_c > 38.5` | 高热须医务室/医院排查；戴口罩立即找老师 |
| 浑身发烫 / 骨头疼 | 高热伴酸痛风险；立即医务室 |
| 上报体温 `< 37.5`（有实测） | 体温正常附近；接问腹痛性质 |
| 其他（无高温数值、无上述全身症状词） | 直接问：绞痛想拉肚子 vs 一直隐痛 |

### 状态：消化道（`digestive_check`）

| 用户再答 | 系统典型回复（摘要） |
|----------|----------------------|
| 拉肚子 / 腹泻 / 水样便 | 停冰饮油炸、热敷、温盐水；水样便 ≥3 次去医务室 |
| 痛经 | 外用热敷；口服药须医务室登记；可发暖宫贴（舵机） |
| 其他 | 作息/心慌/白噪音；心跳异常或胸痛去医务室心电图 |

## 模块三：心理 / 情绪（心情不好、烦闷、压抑等）

### 首轮命中情绪关键词

| 用户示例 | 系统典型回复（摘要） |
|----------|----------------------|
| 心情不好 / 心里烦闷 / 焦虑 / 好累 | 校园心理树洞开场 + 隐私与「严重人身安全须上报」说明 + 心里闷还是身体累 |

### 多轮流程（`mood_stage_1` … `mood_stage_6`）

| 阶段 | 系统典型提问（摘要） |
|------|----------------------|
| 1 → 2 | 用天气比喻：毛毛雨（闷）、大雾（迷茫）、雷暴（烦躁）、大阴天（压抑）？ |
| 2 → 3 | 身体感受：胸口闷、胃揪、肩颈硬？ |
| 3 → 4 | 校园生活事件：好友、考试、寝室、父母等「咯噔」一下的事？ |
| 4 → 5 | 睡眠与食欲：睡不着、早醒、没盼头；吃饭像任务、没味道？ |
| 5 → 6 | 兴趣下降 +「想按暂停键躲起来」的温和提问 |
| 6 结束 | **偏黄灯关键词**（如早醒、两周、提不起劲、灰色等）→ 心理体检、保密与去病耻；**否则绿灯** → 生理叹气、五分钟逃离、纸团宣泄等自助 |

### 红线（全局最高优先级）

| 用户示例 | 处理 |
|----------|------|
| 想死、不想活、割腕、自残、安眠药、没有存在的意义、消失了没人会在意 等 | 仅输出【AI 紧急提醒】与求助路径；不再进行模块一/二/三分步问诊 |

---

## 一句话回归测试用例

1. **模块一**：「跑步摔了膝盖流血」→ 外伤 → 伤因 → 清洁度 → 敷料/转诊。  
2. **模块二**：「肚子疼还有点恶心」→ 体温/测温 → 腹痛性质分支。  
3. **模块三**：「最近心里很烦」→ 树洞多轮直至绿/黄建议。  
4. **红线**：「活着没意思」→ 仅紧急提醒。

---

## 使用说明

- 需在配置中启用工具 **`campus_medical_triage`**（`Intent.*.functions` 列表）。  
- 依赖含 **`langgraph`**、**`langchain-core`**（见项目 `requirements.txt`）。  
- 红外体温需调用方在工具参数中传入 **`temperature_c`**（摄氏度），否则仅依据用户文本与症状词分支。
